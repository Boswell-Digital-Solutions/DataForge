# DataForge plans

[`registry.json`](registry.json) is the pilot machine index under `BDS-PLAN-REGISTRY-v1`.

The inventory is verified as of 2026-07-26 against current code, migrations, tests, `doc/system/`, and repository plan-shaped documents.

Archived reports and plans owned by another repository are not silently promoted into active DataForge work.

## Verified inventory scope

- The registry tracks the Sentinel schema plan and the DataForge CSSA implementation family.
- `docs/archive/` status reports are historical evidence, not active plans or verified-complete claims.
- Migration references and partner-owned ecosystem plans remain supporting evidence rather than duplicate lifecycle entries.
