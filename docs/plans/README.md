# DataForge plans

[`registry.json`](registry.json) is the pilot machine index under `BDS-PLAN-REGISTRY-v1`.

The inventory remains `pending_inventory` while current DataForge plan-shaped documents are reconciled against code, migrations, tests, `doc/system/`, and prior Drive archives. Pending means unknown, not zero.

Archived reports and plans owned by another repository are not silently promoted into active DataForge work.
